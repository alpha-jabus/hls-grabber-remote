HLS Grabber

Токен хранится в профиле Firefox. Перед передачей URL и заголовков сайта (в том числе Cookie/Bearer) Firefox запросит отдельное согласие. Данные отправляются только по твоему действию и только на выбранный сервер. Используй только собственный сервер.

Перехват выключен

Перехват выключен по умолчанию. Включи его для этой вкладки, затем запусти видео. Firefox попросит доступ к сайтам, включая CDN.
