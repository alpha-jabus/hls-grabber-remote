HLS Grabber Настройки

Подключение к серверу и редактирование JSON прямо в Firefox

Подключение

JSON-настройки

Редактирование той же конфигурации без отдельного файла на диске

В JSON виден API-токен. Не копируй конфигурацию в публичные репозитории и чаты. Это содержимое профиля Firefox, а не файл для обмена или публикации.

JSON — альтернативный вид настроек из профиля Firefox (storage.local), а не отдельный client.json. При ошибке введённые данные остаются в форме; последняя сохранённая конфигурация не меняется. Native Messaging нужен только для TLS pinning. Серверные server.env и encryption.key не открываются.

Настройка на сервере

cd ~/hls-grabber-remote/server
bash ./install-server.sh
bash ./enable-tls.sh 192.168.0.190

Команда выведет SHA-256 сертификата. На ПК один раз установи помощник: bash ./install.sh. Открой серверу порт 8765 только с доверенных адресов локальной сети.
