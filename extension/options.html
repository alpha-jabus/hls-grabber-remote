HLS Grabber Настройки

Подключение к серверу и редактирование локального JSON-конфига

Подключение

Конфигурационный файл

Для pinned HTTPS: ~/.config/hls-grabber/client.json

В JSON виден API-токен. Не копируй конфигурацию в публичные репозитории и чаты. Этот файл находится на твоём ПК, а не на сервере.

Firefox не может произвольно редактировать локальные файлы: JSON читает и записывает установленный Native Messaging-помощник. Серверные server.env и encryption.key здесь не открываются.

Настройка на сервере

cd ~/hls-grabber-remote/server
bash ./install-server.sh
bash ./enable-tls.sh 192.168.0.190

Команда выведет SHA-256 сертификата. На ПК один раз установи помощник: bash ./install.sh. Открой серверу порт 8765 только с доверенных адресов локальной сети.
